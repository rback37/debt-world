# Contributing

Thank you for helping Debt World become clearer, safer, and more useful.

## Good public contributions

- Reproducible product bugs without personal financial data.
- Accessibility, device, browser, keyboard, or slow-network findings.
- Wording and translation improvements.
- Respectful proposals for missing debt categories.
- Privacy, moderation, financial-education, and consumer-safety review.

## Before opening an issue

1. Remove all real amounts, names, account numbers, contact details, screenshots of statements, and private conversations.
2. Describe the page, device/browser, steps, expected result, and actual result.
3. Say whether the issue blocks use, affects privacy/safety, or is a normal improvement.

Do not use GitHub to request a loan, promote a service, solicit users, or give personalized legal or financial advice. Private personal feedback belongs in the product’s Feedback panel.

This repository currently contains public product and community documentation, not the production source. A source contribution workflow and license will be added only if the owner later opens a reviewed portion of the codebase.
